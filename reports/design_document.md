# Design Document: Предсказание цен на подержанные автомобили

## 1. Цели и метрики

### 1.1. Целеполагание
**Название:** Used Car Price Prediction  
**Задача:** Предсказание рыночной стоимости подержанного автомобиля на основе характеристик из объявления.  
**Тип задачи:** Регрессия  
**Целевая переменная:** `price` (цена в долларах США)  
**Набор данных:** Used Cars Dataset (платформа Craigslist).  
**Цель:** Построение модели машинного обучения для автоматизированной и точной оценки стоимости подержанных автомобилей.

### 1.2. Бизнес-обоснование
Инструмент ценообразования снижает информационную асимметрию на рынке. Продавцы получают объективную рекомендацию по стоимости продажи, а покупатели — индикатор для выявления переоцененных или подозрительно дешевых предложений.

### 1.3. Метрики
Основная метрика: **MAE (Mean Absolute Error)**.  
Формула: `MAE = mean(abs(y_true - y_pred))`

**Обоснование:**
MAE измеряет среднюю абсолютную ошибку в исходных единицах измерения (долларах), что обеспечивает высокую интерпретируемость для бизнеса. Метрика устойчива к нетипичным ценовым выбросам, которые регулярно встречаются на рынках автомобилей с пробегом. В качестве вспомогательной метрики применяется MAPE для оценки относительной ошибки.

### 1.4. Критерии успеха
- MAE целевой модели ниже MAE базовой модели (Linear Regression).
- Качество предсказаний стабильно на обучающей, кросс-валидационной и тестовой выборках.
- Отсутствует выраженное переобучение.
- Результаты предсказаний поддаются логической интерпретации на основе важности признаков.

## 2. Данные

### 2.1. Описание датасета
**Исходная платформа:** Craigslist  
**Источник:** Kaggle
**Размер исходных данных:** 426 880 строк, 26 признаков.  
**Размер после базовой очистки:** 270 851 строка, 19 признаков.

### 2.2. Проблемы качества данных
- **Целевая переменная (`price`):** Правоскошенное распределение, наличие нулевых цен, экстремально низких значений и завышенных выбросов.
- **Пропуски:** Значительная доля пропусков в категориальных переменных (`cylinders`, `condition`, `drive`, `paint_color`, `type`) и геоданных (`lat`, `long`).
- **Аномалии:** Нереалистичный год выпуска и пробег (0 или более 500 000 миль).
- **Кардинальность:** Текстовые описания (`description`), спецификации моделей (`model`) и локации (`region`) содержат избыточное количество уникальных значений.

### 2.3. Стратегия очистки (Data Cleaning)
| Проблема | Принятое решение |
| :--- | :--- |
| Некорректная цена | Фильтрация: `500 <= price <= 100 000` |
| Некорректный год выпуска | Фильтрация: `year >= 1980` |
| Аномальный пробег | Фильтрация: `0 < odometer <= 500 000`, импьютация среднего для пропусков |
| Пропуски категорий | Заполнение константой `unknown` |
| Пропуски геоданных | Импьютация медианой по штату, затем глобальной медианой |
| Технические признаки | Удаление `id`, `url`, `image_url`, `VIN`, `county`, `size` |

## 3. Генерация признаков (Feature Engineering)
Вся логика извлечения признаков инкапсулирована в scikit-learn совместимый класс `CraigslistFeatureEngineer`.
1. **Возраст автомобиля (`car_age`):** Разница между базовым годом (2022) и годом выпуска `year`.
2. **Логарифмирование пробега (`log_odometer`):** Нормализация распределения.
3. **Ценовые кластеры:** Признаки `region` и `paint_color` кластеризуются алгоритмом KMeans на основе медианной цены для снижения размерности.
4. **Агрегация моделей:** Редкие значения в признаке `model` (менее 20 вхождений) объединяются в категорию `other`.
5. **Текстовые описания (`description`):** Применение `TfidfVectorizer` для извлечения значимых n-грамм.

---

## 4. Пайплайн и обучение (Training)

### 4.1. Архитектура пайплайна
Процесс обучения реализован как единый граф трансформаций `sklearn.pipeline.Pipeline`, состоящий из трех этапов:
1. `CraigslistFeatureEngineer`: очистка пропусков, генерация числовых признаков и кластеризация.
2. `ColumnTransformer`: кодирование категориальных признаков через `OneHotEncoder` (с параметром `handle_unknown='ignore'`) и векторизация текста через `TfidfVectorizer`.
3. Модель машинного обучения.

### 4.2. Обработка целевой переменной
Для устранения проблемы правоскошенного распределения цен применяется `TransformedTargetRegressor`. Целевая переменная логарифмируется (`np.log1p`) перед обучением модели, а при формировании предсказания применяется обратное экспоненциальное преобразование (`np.expm1`). Это стабилизирует процесс сходимости градиентных методов и возвращает корректную метрику MAE в долларах.

---

## 5. Валидация (Validation)

### 5.1. Стратегия разбиения данных
- **Train/Test Split:** Очищенный набор данных разбивается на обучающую (70%) и отложенную тестовую (30%) выборки. Тестовая выборка изолирована на всех этапах разработки и используется исключительно для финальной проверки обобщающей способности модели.
- **Cross-Validation:** Внутри обучающей выборки применяется KFold кросс-валидация (3 сплита) для оценки стабильности модели и настройки гиперпараметров.

### 5.2. Изоляция утечек данных (Data Leakage)
Все трансформаторы пайплайна, включая методы импьютации и кластеризации, обучаются (`fit`) строго на тренировочных фолдах. Тестовая и валидационная выборки подвергаются только преобразованию (`transform`).

## 6. Выбор модели (Model Selection)

Отбор финального алгоритма производился путем сравнения нескольких базовых моделей и градиентных бустингов. Подбор гиперпараметров осуществлялся через `GridSearchCV` с оптимизацией целевой метрики `neg_mean_absolute_error`.

### 6.1. Сравнительный анализ алгоритмов
1. **DecisionTreeRegressor:** Наименьшая стабильность. Подвержен сильному переобучению без жестких ограничений глубины. MAE: ~6800.
2. **RandomForestRegressor:** Высокое качество предсказаний благодаря бэггингу. Требует больших затрат оперативной памяти и времени на инференс. MAE: ~5400.
3. **XGBoost:** Классическая реализация градиентного бустинга. Быстрое обучение, хорошие метрики. MAE: ~5028.
4. **CatBoostRegressor:** Оптимальный выбор среди изолированных моделей. Эффективно обрабатывает разреженные данные после OHE и текстовых векторизаторов. MAE: ~4908.

### 6.2. Финальное решение (Ensemble)
Для достижения максимального качества был реализован ансамбль **StackingRegressor**.
- **Алгоритмы 0-го уровня (Base Estimators):** Random Forest, XGBoost и CatBoost, инициализированные с оптимальными гиперпараметрами, найденными в процессе кросс-валидации.
- **Мета-модель 1-го уровня (Final Estimator):** Линейная регрессия с L2-регуляризацией (`Ridge`).

Ансамбль комбинирует предсказания бустингов и случайного леса, нивелируя ошибки отдельных моделей. Финальная метрика MAE на кросс-валидации составила **~4745**. Данный ансамбль интегрирован в итоговый артефакт `models/final_model.pkl` для работы в production.

## 7. Анализ ошибок (Error Analysis)

По результатам проверки финальной модели на отложенной выборке установлены следующие закономерности:

1. **Характер максимальных ошибок:** Наибольшие абсолютные отклонения (Residuals) фиксируются на коллекционных ретро-автомобилях (старше 1995 года) и автомобилях с глубоким кастомным тюнингом. Ценообразование в данных сегментах зависит от уникальных качественных характеристик, не представленных в табличном виде.
2. **Относительные ошибки (MAPE):** Максимальная процентная ошибка характерна для автомобилей ультранизкого ценового сегмента (1995–2004 г.в.). Незначительное абсолютное отклонение (например, $1500) при базовой цене автомобиля $3000 формирует ошибку в 50%.
3. **Важность признаков (Permutation Feature Importance):** Метод перестановочной важности выявил основные факторы, влияющие на ценообразование в рамках построенного пайплайна:
   - Возраст автомобиля (`year` / `car_age`);
   - Заявленный пробег (`odometer`);
   - Бренд-производитель (`manufacturer`);
   - Тип привода (`drive`);
   - Ключевые термины, извлеченные из текстового описания (`description`).
